## 🧠 About

I'm a B.Tech Computer Science student specializing in Cybersecurity at Mohan Babu University. Most of my time right now goes into Java and Data Structures & Algorithms — getting the fundamentals solid before branching out further. I'd rather turn what I learn into small, real projects than let it stay theoretical, which is what CampusConnect and WeDonate below are about.
